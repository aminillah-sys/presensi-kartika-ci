# Sistem Presensi & Pendataan Tim - PT Kartika Cipta Indonesia

Sistem Presensi dan Rekapitulasi Terpadu berbasis **Google Apps Script** dan **Vercel Cloud**.

## 🌐 Live Web App
- **Production URL:** [https://presensi-kartika-ci.vercel.app](https://presensi-kartika-ci.vercel.app)
- **Alternative URL:** [https://presensi-kartika-ci-aminillah.vercel.app](https://presensi-kartika-ci-aminillah.vercel.app)

## 🚀 Fitur Utama
1. **Presensi Mandiri Tanpa Dropdown:** Otomatis mengikat akun karyawan yang sedang login.
2. **Kamera Selfie & Kompresi:** Bukti kehadiran instan dengan kompresi Canvas otomatis.
3. **Portal Multi-Peran:** Login Karyawan (EMP-xxx) & Administrator (dmin).
4. **Dashboard & Rekap:** Filter tanggal, status, pencarian, dan Ekspor CSV.
5. **Kelola Tim & Reset PIN:** Manajemen data karyawan dan kata sandi tim.
6. **In-App Password Manager:** Ganti password administrator langsung dari modal web.

## 🛠️ Arsitektur & Teknologi
- **Frontend:** Single Page Application (HTML5, Tailwind CSS, Vanilla JS)
- **Backend:** Google Apps Script (code.gs) & REST JSON
- **Database:** Google Sheets (setup.gs Safe Migration)
- **Storage:** Google Drive (Foto Selfie Bukti)
- **Cloud Hosting:** Vercel
